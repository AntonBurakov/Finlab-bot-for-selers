# PayrixBot

**PayrixBot** — корпоративный стартап, помогающий селлерам маркетплейсов привлекать финансирование, анализировать риски и получать рекомендации по улучшению бизнес-показателей.

---

## Возможности
- Сбор данных по ИНН через Checko API и Wildberries API  
- Автоматический анализ рисков (скоринг)  
- Генерация персональных рекомендаций (Yandex GPT)  
- Загрузка и обработка пользовательских исторических данных (файлы)  
- Кэширование запросов для ускорения работы (Redis)  

---

## Как работает система

### Для физлиц (ИП, ИНН — 10 цифр)
1. Пользователь вводит ИНН в боте.  
2. Система определяет, что это **физлицо** (10-значный ИНН).  
3. Из **Checko API** подтягиваются данные по эндпоинтам:
   - `/person` — информация о физлице  
   - `/entrepreneur` — данные о деятельности ИП  
   - `/legal-cases` — судебные дела  
   - `/inspections` — проверки контролирующих органов  
4. Риски анализируются модулем `checko_core.py`.  
5. Результат скоринга передается пользователю в Telegram.  

### Для юрлиц (компаний, ИНН — 12 цифр)
1. Пользователь вводит ИНН.  
2. Система определяет, что это **юрлицо** (12-значный ИНН).  
3. Из **Checko API** подтягиваются данные по эндпоинтам:
   - `/company` — сведения о компании  
   - `/legal-cases` — судебные дела  
   - `/inspections` — проверки  
   - `/finances` — финансовая отчетность  
   - `/enforcements` — исполнительные производства  
4. Риски анализируются модулями `checko_core.py` и `checko_scoring_module.py`.  
5. При необходимости генерируются рекомендации через **Yandex GPT**.

## Источники данных и их обработка

| Источник            | Назначение                     | Обрабатывающий модуль       |
|---------------------|--------------------------------|----------------------------|
| **Checko API**      | Сведения о компании или ИП, судебные дела, проверки, финансы, исполнительные производства | `checko_core.py'|
| **Wildberries API** | Категории товаров, обороты, ассортимент | `wb_core_full_from_notebook.py` |
| **Файлы (CSV/XLSX)**| Исторические данные селлера (продажи, обороты) | `get_seller_data_from_csv.py` |
